PhonePe Landing Page 

A simple and responsive PhonePe-inspired landing page created for learning and practicing front-end web development.

📌 Project Description

This project is a basic clone of a PhonePe landing page. It includes a navigation bar, hero section, download buttons, feature cards, images, and icons.
The website is designed to be responsive and works on desktop, tablet, and mobile devices.

🛠️ Technologies Used :
HTML5 – Website structure
CSS3 – Styling and layout
Bootstrap 5 – Responsive design, grid system, buttons, and layout
Iconify – Custom and brand icons
unpkg CDN – Used to load the Iconify icon library

✨ Features :
Responsive navigation bar
Responsive layout using Bootstrap Grid
Hero section with text and image
Download buttons with Apple and Google Play icons
Feature sections :
Responsive images using Bootstrap
Custom icons such as cash and voting icons
Mobile and tablet support
